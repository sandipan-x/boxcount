# BoxCount

Moving box calculator: build your box list room by room, get counts by size plus tape, paper and wrap — with a printable checklist. Free tool.

## Features
- Room-by-room sticky-note builder with add/remove and a stuff-level multiplier
- Box-size shopping list with tape, paper and bubble-wrap math
- Printable packing manifest checklist
